<p>

O front-end do Nutrifacil é uma aplicação moderna construída com React, utilizando a base do Create React App. Abaixo estão as principais ferramentas e scripts utilizados no desenvolvimento.
</p>



### Pré-requisitos

<p>
Para garantir a compatibilidade, certifique-se de estar utilizando o Node.js na versão 18.x.
</p>

### Scripts Disponíveis

<p>
No diretório do projeto, você pode executar os seguintes comandos:
</p>

<p>

- `npm start` Inicia o servidor de desenvolvimento.
  - Abra http://localhost:3000 para visualizar a aplicação no navegador.
  - A página será recarregada automaticamente após qualquer alteração no código.

</p>

<p>

- `npm run build` Gera a versão de produção da aplicação na pasta build. 
  - Este comando otimiza e minifica os arquivos para o melhor desempenho.
</p>


<p>

- `npm test` Executa os testes automatizados em modo interativo.
  - A aplicação utiliza a React Testing Library como principal ferramenta para garantir a qualidade dos componentes.
</p>


### Principais Ferramentas

<p>

- React e React DOM: Biblioteca principal para a construção da interface de usuário e sua renderização no navegador.

- React Icons: Biblioteca utilizada para a fácil inclusão de ícones de diversas fontes (Font Awesome, Material Icons, etc.) na interface.

- Azure Static Web Apps CLI: Ferramenta de desenvolvimento para emular o ambiente do Azure localmente, facilitando os testes antes do deploy final.

</p>
